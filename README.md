# Samarth Classes

A scaffold for the Samarth Classes portal with separate teacher and student access paths.

## Features

- Teacher portal with attendance, exam creation, and reports
- Student portal with assigned exam visibility and notifications
- Role-based registration and login flow
- Tailwind CSS / Next.js UI skeleton
- Supabase client placeholder for authentication and database integrations

## Next steps

1. Run `npm install`
2. Set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. Implement Supabase auth, student/teacher role enforcement, and protected APIs
4. Add attendance and exam database tables as described in the architecture
